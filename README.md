# Livestock Management System

Web-based livestock management system for managing farm data and livestock sales.

## Features
- Livestock data management
- Farm monitoring
- Sales management
- Dashboard system
- Data input and update
- Livestock sales recording
- Farm activity monitoring

## Technologies
- PHP
- Laravel
- HTML
- CSS
- MySQL

## Framework & Database
- Laravel Latest Version
- MySQL Database

## System Functions
- Add livestock data
- Update livestock information
- Monitor farm activities
- Manage sales transactions
- Store livestock data into database
- Display livestock information dashboard

## Database
The system uses MySQL database for storing:
- Livestock data
- Farm information
- Sales transactions
- User data
